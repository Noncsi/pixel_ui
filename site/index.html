Pixel UI

A pixel-art game UI kit, built as framework-agnostic Web Components.

    Components on this screen

      Every component

      Thirty-four components, forty-one custom elements. Each one wraps the platform rather than reimplementing it, carries its own accessible name and keyboard behaviour, and is themed entirely through --px-* custom properties.

        Built with Lit 3 and no framework. Tested with Vitest and happy-dom, documented in Storybook, themed with CSS custom properties in two themes.
